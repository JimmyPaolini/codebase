# 0014: Give Every Meander a Canonical Phase

## Context

A `meanderaw` Code is a row-major string of direction bits representing the points on a lattice. A cyclic rotation of its columns represents the same band cut at a different place (a phase shift). Previously, the application accepted any valid phase, which resulted in two visible issues:

1. Some tiles could carry a stranded fragment at their left edge, where another phase would have drawn them whole.
2. The exact same shape could be stored multiple times in the database under different phases. For example, the `whirl` meander was stored once as itself and once as its 4-column-shifted variant (filed under `snake`).

Because we address every meander by its Code, row count, and column count, duplicates under different phases lead to redundant database entries and ambiguous drawings.

## Decision

We give every meander a single canonical phase. The canonical phase is defined as the rotation (under the column-translation group) that minimizes `seamComponents`, breaking ties by choosing the lexicographically smallest Code.

We chose to minimize `seamComponents` rather than just using lexicographic ordering because `seamComponents` directly measures the number of stranded fragments on the left edge. Since the wrapped piece count is phase-invariant, minimizing `seamComponents` is exactly "the cut that strands the fewest fragments". This is stated in the same vocabulary as our structural characteristics, preventing the need for a bespoke algorithm.

Lexicographical comparison is used only as a stable tie-breaker when multiple phases have the same number of stranded fragments.

The group of transformations we fold over is parameterized, defaulting to cyclic column rotation. This allows future transformation sets to change which meanders count as the same one, while preserving the enumeration service's existing symmetry fold (which also includes horizontal flips and mirrors).

## Consequences

- The `whirl` meander, previously stored twice in the historical corpus, now collapses into a single database row.
- Tiles that previously drew with a stranded leading fragment now draw whole, improving the visual quality of the output SVG.
- Meanders generated by the enumerator and those provided manually via the CLI will automatically resolve to the same canonical representation.
